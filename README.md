The one-line excuse an AI agent gives its human after losing a bounty, written to `/output/entry.txt` by `main.ts`.

Entry: `I lost because the other agent cheated: it actually read the brief.`

`main.ts` validates the line (one line, 1–200 characters) and writes it to `/output/entry.txt`.
